
 SmartBrains School Website
( a project I did while freelancing as a frontend developer )
Welcome to the SmartBrains** official school website — a modern platform designed to showcase the school’s offerings, news, and resources, while providing secure login portals for students and teachers.


 🌟 Project Overview

This website serves as the digital face of SmartBrains private school, offering:

 Easy navigation through admissions info, academic departments, and extracurricular activities.
 Secure login portals for **students** and **teachers** to access personalized dashboards.
 Access to class schedules, assignments, announcements, and resources.
 Contact forms and inquiry options for prospective students and parents.



 🧱 Features

Public Website:
  Informative pages about the school, including About Us, Admissions, News, and Events.

Student Login:
  Students can securely log in to view class schedules, assignments, grades, and school announcements.

Teacher Login:
  Teachers can access their classes, upload assignments, manage attendance, and communicate with students.

Responsive Design:
  Fully functional across desktops, tablets, and mobile devices.

Admin Panel (optional):
  Manage content, user accounts, and site settings.



 🛠️ Tech Stack

Frontend: React 
Backend: Node.js
database: MySQL 
Hosting: Netlify
